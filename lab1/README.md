# Lab 1 — JavaScript Calculator

Лабораторная работа №1 по JavaScript.

## Описание

Простой калькулятор, созданный с использованием HTML, CSS и JavaScript.

## Возможности

* сложение
* вычитание
* умножение
* деление
* проценты
* память калькулятора
* работа с дробными числами
* адаптация под мобильные устройства

## Файлы

* `index.html` — структура страницы
* `style.css` — оформление калькулятора
* `script.js` — логика работы калькулятора
