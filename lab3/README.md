# Lab 3 — Конвертер валют

Лабораторная работа №3 по JavaScript.

## Описание

Приложение «Конвертер валют», созданное с использованием HTML, CSS и JavaScript. Приложение позволяет конвертировать суммы между различными валютами по актуальным курсам Центрального банка России.

## Возможности

* конвертация валют;
* выбор исходной и целевой валюты;
* ввод чисел с помощью экранной клавиатуры;
* очистка суммы с помощью кнопки AC;
* удаление последнего введённого символа;
* поиск валют по коду и названию;
* подсветка активного поля и выбранной валюты;
* загрузка курсов валют через API;
* адаптация интерфейса под мобильные устройства.

## Используемые технологии

* HTML — структура приложения;
* CSS — оформление интерфейса и адаптивная вёрстка;
* JavaScript — логика конвертации и взаимодействия с интерфейсом;
* money.js — конвертация валют;
* API Центрального банка России — получение курсов валют.

## Файлы проекта

* `index.html` — структура страницы;
* `style.css` — оформление приложения;
* `script.js` — логика работы конвертера;
* `icons/` — иконки приложения.

## API

Для получения курсов валют используется [API Центрального банка России](https://www.cbr-xml-daily.ru/daily_json.js).
