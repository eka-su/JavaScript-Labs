# Lab 5 — Tracker

Лабораторная работа №5 по JavaScript.

## Описание

Приложение «Tracker» — одностраничный трекер криптовалют, созданный без сторонних фреймворков с использованием HTML, CSS и JavaScript. Приложение получает актуальные данные с CoinGecko API, показывает рынок криптовалют, исторические графики и позволяет вести собственный инвестиционный портфель.

## Возможности

* просмотр топ-100 криптовалют по рыночной капитализации;
* отображение ранга, названия, текущей цены, изменения за 24 часа и капитализации;
* поиск монеты по названию или тикеру;
* фильтрация монет по минимальной и максимальной цене;
* сортировка таблицы по клику на заголовок столбца;
* переключение между страницами «Рынок», «Детали монеты» и «Портфель» без перезагрузки;
* открытие страницы монеты по динамическому hash-маршруту;
* отображение исторического графика цены с помощью Chart.js;
* выбор таймфрейма: 1 день, 7 дней, 30 дней или 1 год;
* конвертация монеты в USD, EUR и BTC;
* добавление транзакций в инвестиционный портфель;
* расчёт вложенной суммы, текущей стоимости и общей прибыли или убытка;
* удаление операций из портфеля;
* сохранение портфеля в localStorage;
* синхронизация портфеля между двумя вкладками браузера;
* задержка поиска с помощью собственной функции debounce на 300 мс;
* автоматическое обновление цен каждые 45 секунд;
* отображение индикатора обновления данных;
* сохранение текущей прокрутки таблицы при автообновлении;
* обработка сетевых ошибок и ограничения API 429 Too Many Requests;
* безопасная вставка названий монет через textContent.

## Используемые технологии

* HTML — структура приложения и страницы SPA;
* CSS — минималистичное оформление, карточки и адаптивная вёрстка;
* JavaScript — состояние приложения, роутинг, запросы, фильтры и расчёты;
* JavaScript Modules — разделение кода через import/export;
* Fetch API — получение данных с CoinGecko;
* Chart.js — построение исторического графика цены;
* localStorage — сохранение данных портфеля;
* StorageEvent и BroadcastChannel — синхронизация между вкладками;
* CoinGecko API — данные о криптовалютах и курсах.

## Файлы проекта

* `index.html` — основная HTML-страница приложения;
* `styles.css` — стили, группы интерфейса и адаптивная вёрстка;
* `js/app.js` — запуск приложения, роутинг и связывание модулей;
* `js/state.js` — единый объект state и функции обновления состояния;
* `js/api.js` — запросы к CoinGecko API и обработка HTTP-ошибок;
* `js/market.js` — таблица рынка, поиск, фильтры и сортировка;
* `js/coin.js` — детали монеты, график и конвертер;
* `js/portfolio.js` — форма транзакций и расчёты портфеля;
* `js/storage.js` — localStorage и синхронизация вкладок;
* `js/utils.js` — общие функции DOM, форматирования и debounce.
* `CODE_GUIDE.md` — учебная версия всего кода проекта с пояснениями строк и функций.

## Архитектура состояния

Приложение использует один объект `state`, который хранит:

* данные рынка криптовалют;
* список транзакций портфеля;
* текущие фильтры и сортировку;
* активный маршрут;
* выбранный таймфрейм и данные графика;
* состояние загрузки и обновления.

Изменение данных выполняется через функции из `state.js`. После изменения вызывается общая функция `render()`, которая обновляет интерфейс на основе текущего состояния.

## Страницы приложения

### Рынок

Главная страница содержит таблицу топ-100 криптовалют, поиск, фильтрацию по цене и сортировку по столбцам.

### Детали монеты

На этой странице отображаются текущая цена, изменение за 24 часа, исторический график и конвертер.

### Портфель

На этой странице пользователь выбирает монету, количество и цену покупки. После добавления приложение рассчитывает текущую стоимость и прибыль или убыток.

## Статистика портфеля

В портфеле отображаются следующие показатели:

* **Вложено** — сумма всех покупок;
* **Текущая стоимость** — стоимость активов по актуальным ценам API;
* **Прибыль / убыток** — разница между текущей стоимостью и вложениями;
* **Процент изменения** — прибыль или убыток относительно вложенной суммы;
* **Список операций** — монета, количество, цена покупки и текущая стоимость.

## Обновление и ошибки API

Цены обновляются автоматически каждые 45 секунд с помощью `setInterval`. Во время запроса показывается spinner. Если CoinGecko возвращает ошибку или ограничивает количество запросов, приложение не прекращает работу, а показывает уведомление пользователю.
