# Lab 4 — TypingTest

Лабораторная работа №4 по JavaScript.

## Описание

Приложение «TypingTest» — тренажёр слепой печати, созданный с использованием HTML, CSS и JavaScript. Приложение позволяет проверять скорость и точность набора текста в двух режимах: по времени и по количеству слов.

## Возможности

* тестирование скорости печати по времени;
* тестирование по заданному количеству слов;
* выбор продолжительности теста: 10, 25, 50 или 100 секунд;
* выбор количества слов: 10, 25, 50 или 100;
* подсветка правильно и неправильно введённых символов;
* выделение слов с ошибками;
* отображение курсора во время печати;
* автоматическая прокрутка текста во время теста;
* отображение прогресса в режиме слов;
* автоматическое завершение теста по истечении времени;
* автоматическое завершение теста при переходе на другую вкладку;
* отображение статистики после завершения теста;
* расчёт скорости печати (CPM), точности, количества символов и ошибок;
* возможность перезапустить тест или перейти к следующему тексту;


## Используемые технологии

* HTML — структура приложения;
* CSS — оформление интерфейса и адаптивная вёрстка;
* JavaScript — логика тестирования, обработка ввода и расчёт статистики;
* Google Fonts — шрифт Roboto Mono;

## Файлы проекта

* `index.html` — структура страницы;
* `style.css` — оформление приложения;
* `script.js` — логика работы тренажёра;
* `icons/` — SVG-иконки приложения 

## Статистика

После завершения теста отображаются следующие показатели:

* **CPM** — количество правильно введённых символов в минуту;
* **Точность** — процент правильно введённых символов;
* **Символы** — общее количество введённых символов;
* **Ошибки** — количество символов, не совпавших с исходным текстом;
* **Тип теста** — выбранный режим и его параметры.

## Завершение теста

В режиме времени тест автоматически завершается по истечении выбранного времени. В режиме слов тест завершается после ввода заданного количества слов. Если пользователь переключается на другую вкладку во время активного теста, тест также завершается и отображается статистика.
