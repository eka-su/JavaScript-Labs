# Lab 2 — TodoList

Лабораторная работа №2 по JavaScript.

## Описание

Приложение TodoList, созданное с использованием HTML, CSS и JavaScript.

## Возможности

* добавление задач;
* редактирование задач;
* удаление задач;
* отметка задачи как выполненной;
* зачёркивание выполненных задач
* сохранение задач в localStorage;
* адаптация под мобильные устройства

## Файлы

* `index.html` — структура страницы
* `style.css` — оформление TodoList
* `script.js` — логика работы калькулятора
* `icons/` — иконки приложения
